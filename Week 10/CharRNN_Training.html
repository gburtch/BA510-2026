Step 2: Text Vectorization — Characters → Integers
A TextVectorization layer lives inside the model. It splits each 100-char string into individual characters and maps each one to a unique integer from 0–66. The model never sees letters — only integers.
① Each character in X gets its own integer ID
First 10 characters of X — watch them split and get mapped:
② The full vocabulary — 67 unique characters
int 0 = [PAD]
int 1 = ' ' (space)
int 2 = '\n' (newline)
int 3–12 = digits 0–9
int 13–38 = A–Z (uppercase)
int 39–64 = a–z (lowercase)
int 65–66 = punctuation ( : , . ! ? … )
67 unique characters → each gets a stable integer 0–66.
TextVectorization builds this mapping automatically by scanning the training data once (.adapt()).
Output shape after TextVectorization: (batch_size, 100) — a 2-D tensor of integers, one row per training sequence. This feeds directly into the Embedding layer next.

Same Dense layer, applied 6 times. The weight matrix is shared across positions. Only the input (the hidden state) differs per row. This is what the output shape (batch, 100, 67) means.
Step 6: Loss & Backpropagation
At every position, the predicted character is compared against the actual next character. Cross-entropy loss is computed and averaged. Gradients flow backward to update all weights.

Step 1 — building training examples
# The full Shakespeare text is ~1.1 MB of characters # ── Create offset copies for X and y ──────────── features = list(split_input(shakespeare[:-1], 100)) labels = list(split_input(shakespeare[1:], 100)) # ↑ same text, shifted by 1 # Each element of features / labels is a 100-char string # features[0] = "First Citizen:\nBefore we proceed …" # labels[0] = "irst Citizen:\nBefore we proceed a…" # ── Bundle into a tf.data.Dataset ──────────────── dataset = tf.data.Dataset.from_tensor_slices( (features, labels)) training_data = (dataset .batch(64) .cache() .shuffle(10_000)) # result: 174 windows of 100 chars each # target = input shifted by 1 char at every position
Step 2 — TextVectorization: char → integer
# TextVectorization lives INSIDE the model ─────── # Raw strings go in; integer tensors come out. text_input = layers.Input( shape=(1,), dtype="string") x = layers.TextVectorization( standardize=None, # keep punctuation split="character", # one token per char output_sequence_length=100, # pad/truncate → 100 )(text_input) # output shape: (batch, 100) integers 0–66 # Fit the vocabulary to the training data once: tokenizer.adapt(dataset.map(lambda x, y: x)) # After .adapt(): 67 unique characters discovered # Each char maps to a stable int 0–66 forever # Example mappings: # 'F' → 25, 'i' → 11, ' ' → 1, '\n' → 2
Step 3 — embedding lookup
# Model receives integer token IDs inputs = layers.Input( shape=(sequence_length,), # 100 integers dtype="int", ) # Embedding: int → 256-dim dense vector ───────── # Each integer is a ROW INDEX into this table # int 28 → retrieve row 28 → 256-dim vector x = layers.Embedding( input_dim=67, # vocabulary size output_dim=256, # embedding dimension )(inputs) # Output shape: (batch, 100, 256) # The 67×256 table is LEARNED during training. # Initially random; after training, similar chars # have similar vectors (close in embedding space).
Step 4 — GRU recurrent layer
# Input: (batch, 100, 256) — embeddings # At each timestep t: # h_t = GRU(embedding_t, h_{t-1}) # h_t → output (to Dense) AND new state x = layers.GRU( 1024, # hidden units return_sequences=True, # ← collect ALL h_t )(x) # Output shape: (batch, 100, 1024) # return_sequences=True → h_1, h_2, …, h_100 # return_sequences=False → only h_100 (inference) # The same 1024-dim vector: # → passed RIGHT as the next GRU call's state # → passed DOWN into Dense(67) for prediction # These are not separate tensors — it is one h_t. x = layers.Dropout(0.1)(x) # light regularization
Step 5 — Dense + Softmax
# Input: (batch, 100, 1024) — all hidden states # Dense applied INDEPENDENTLY at every position # # h_1 → Dense → softmax → 67 probs → argmax → ĉ₁ # h_2 → Dense → softmax → 67 probs → argmax → ĉ₂ # … # h_100 → Dense → softmax → 67 probs → ĉ₁₀₀ outputs = layers.Dense( vocabulary_size, # 67 activation="softmax", # 67-class distribution )(x) # Output shape: (batch, 100, 67) # Same Dense weights reused across all 100 positions. # All 100 predictions happen in one forward pass. model = keras.Model(inputs, outputs) model.summary() # Embedding params: 67 × 256 = 17,152 # GRU params: 3 × (256+1024) × 1024 = 3,938,304 # Dense params: 1024 × 67 + 67 = 68,675
Step 6 — loss & training
# Compile: specify loss function and optimizer ── model.compile( optimizer="adam", loss="sparse_categorical_crossentropy", # ↑ targets are integer IDs, not one-hot metrics=["sparse_categorical_accuracy"], ) # labels = input shifted by 1 character # "First Citizen:" → target: "irst Citizen:B" # Loss averaged across ALL positions × ALL batches model.fit(training_data, epochs=20) # Epoch 1: loss 0.79 (near-random predictions) # Epoch 20: loss 0.65 (learned Shakespeare prose) # Backprop updates all weights simultaneously: # Dense weights ← predict char distributions # GRU weights ← build useful hidden states # Embedding rows ← represent chars well
